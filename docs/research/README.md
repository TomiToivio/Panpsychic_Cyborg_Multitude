# PCM Research Index

This directory contains the working research layer of **Panpsychic Cyborg Multitude (PCM)**. It is an index, not a second source of truth: each linked document remains responsible for its own argument, while [`SOURCES.md`](SOURCES.md) is the canonical bibliography for scholarly sources.

Document labels used here:

- **paper** — sustained research argument intended to stand on its own;
- **research note** — focused conceptual or empirical synthesis;
- **research plan** — programme or experimental agenda;
- **integration note** — bridge between PCM and an external theory/tool/research programme;
- **checkpoint** — time-bounded empirical scan;
- **weak-signal note** — explicitly exploratory or speculative material.

## Navigation rules

1. Add scholarly references to [`SOURCES.md`](SOURCES.md) first; do not create new parallel source lists unless there is a strong reason.
2. Add a new research document to the most relevant section of this index when it becomes part of the public research layer.
3. Keep **paper**, **plan**, **research note**, **integration note**, **checkpoint**, and **weak-signal note** distinct where that status affects interpretation.
4. Preserve PCM’s central epistemic separation:

```text
COGNITION != CONSCIOUSNESS
AGENCY != SUBJECTIVITY
COLLECTIVE INTELLIGENCE != COLLECTIVE CONSCIOUSNESS
SPECULATION != EVIDENCE
```

The index should grow more slowly than the research layer itself. Its job is navigation, not duplication.
