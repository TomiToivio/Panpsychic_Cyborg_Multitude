01 / POLITICAL ONTOLOGY

Three words.
One operating system.

P

Panpsychic

The boundary of mind stays open. PCM does not require panpsychism as doctrine; it treats substrate certainty with suspicion and keeps is_conscious: UNKNOWN load-bearing.

C

Cyborg

The human–technology boundary has already dissolved. The merge is not tomorrow’s event. The live political question is who governs the assemblage.

M

Multitude

The many act in common without becoming a sovereign One. Rhizomes coordinate, dissent persists, and the Common remains collectively governed.

04 / RHIZOME KERNEL

Memory. Voice. Decision.

PCM is not only a manifesto. The repository contains a working local-first kernel with event-sourced memory, proposals, votes, signed node identities, capability grants and optional networking.

MEMORY

Append-only event log

History belongs to the members and can be replayed rather than silently rewritten.

GOVERNANCE

Proposals + votes

Decision-making records dissent rather than flattening it out.

IDENTITY

did:key + signatures

Nodes authenticate messages cryptographically while authority remains policy-bound.

FABRIC

Zenoh networking

Distributed nodes communicate without turning a platform into the sovereign center.

CAPABILITY

Fail-closed authority

Reachable is not authenticated; authenticated is not authorized; capability is not authority.

EXTENSIONS

BCI + embodiment

Optional, consent-gated interfaces add biosignal context and physical agency without bloating the kernel.
